ShopRadar 隐私政策 / Privacy Policy

Last updated: 2026-05-19

ShopRadar is a Chrome extension that helps users detect Shopify stores and view product summaries. This page describes how we handle data when you use the extension and our API at api.shopradar.uk.

我们收集的数据 / Data we collect

  • Device ID — A random identifier stored in your browser (Chrome storage) to enforce free daily limits and Pro subscription.
  • Store domain — The hostname of the shop you visit while using the extension.
  • API usage — Requests to our servers for authentication, quota, and Pro status.

用途 / How we use data

  • Provide free tier limits and paid Pro features (including CSV export).
  • Process payments through Lemon Squeezy (your Device ID may be sent in checkout metadata).

存储 / Data storage

  • Server-side data is stored on our infrastructure (Vultr).
  • Some data is cached locally in your browser by the extension.

第三方 / Third parties

  • Lemon Squeezy (payments)
  • Cloudflare (DNS / CDN)
