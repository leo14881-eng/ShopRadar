# ShopRadar 服务器从零部署

## 方案（固定）

| 项目 | 路径 |
|------|------|
| 服务器目录 | `/root/shopradar-backend/`（整仓代码） |
| API 后端 | `/root/shopradar-backend/shopradar-server/` |
| 环境变量 | `shopradar-server/.env`（本机填好再上传） |
| 域名 | `api.shopradar.uk` |

---

## 步骤 1 — 本机准备

1. 编辑 `shopradar-server/.env`，确认已填真实密钥（无 `your_*`）
2. **（可选）改 Nginx 模板**  
   打开 `shopradar-server/deploy/nginx.conf`，确认这一行是你的 API 域名：
   ```nginx
   server_name api.shopradar.uk;
   ```
   > 若跳过：`bootstrap.sh` 会用 `export SHOPRADAR_DOMAIN=...` 自动替换 `api.yourdomain.com` 占位符。
3. 打开 ShopRadar 项目，确认 `.vscode/sftp.json` 存在

---

## 步骤 2 — SSH 清空服务器

```bash
ssh root@192.248.179.25
```

登录后执行：

```bash
pm2 delete shopradar-api 2>/dev/null || true
pm2 save 2>/dev/null || true
rm -f /etc/nginx/sites-enabled/shopradar-api
rm -f /etc/nginx/sites-available/shopradar-api
nginx -t 2>/dev/null && systemctl reload nginx || true
rm -rf /root/shopradar-backend
mkdir -p /root/shopradar-backend
ls /root/shopradar-backend/
```

应只有空目录，然后 `exit` 退出 SSH（或保持开着也行）。

---

## 步骤 3 — 上传代码

1. 在 Cursor 打开 **ShopRadar 根目录**（含 `manifest.json` 的那层）
2. `Ctrl+Shift+P` → **SFTP: Upload Project**
3. 选择 **Vultr-整仓上传**，输入 root 密码
4. 等上传完成

## 步骤 5 — 一键并网（含 Nginx + HTTPS）

`bootstrap.sh` 会：

1. 把 `deploy/nginx.conf` 复制到 `/etc/nginx/sites-available/shopradar-api`
2. 用 `SHOPRADAR_DOMAIN` 替换配置里的域名
3. `nginx -t` 并 reload
4. Certbot 申请 HTTPS 证书

```bash
export SHOPRADAR_DOMAIN=api.shopradar.uk
export CERTBOT_EMAIL=leo14881@icloud.com
bash /root/shopradar-backend/shopradar-server/deploy/bootstrap.sh
```

**若并网后只改了 Nginx、要手动生效：**

```bash
nano /etc/nginx/sites-available/shopradar-api
nginx -t && systemctl reload nginx
```

## 常见问题

**PM2 报 `sqlite3` / `invalid ELF header`**：在服务器执行  
`cd /root/shopradar-backend/shopradar-server && rm -rf node_modules && npm install --omit=dev && pm2 restart shopradar-api`

**Certbot 超时**：Vultr 防火墙放行 80/443；Cloudflare 先把 `api` 记录改为 **仅 DNS（灰云）** 再跑 certbot。
