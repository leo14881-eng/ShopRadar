# ShopRadar 后端 — 从零部署（清空重来）

只部署 **API**，不传 Chrome 扩展。服务器目录固定为 `/root/shopradar-backend/`。

---

## 步骤 0：本机检查

1. 已填好 `shopradar-server/.env`（无 `your_*` 占位符）
2. `.vscode/sftp.json` 中 `context` = `./shopradar-server`，`remotePath` = `/root/shopradar-backend`

---

## 步骤 1：SSH 清空服务器（复制整段）

```bash
pm2 delete shopradar-api 2>/dev/null || true
pm2 save 2>/dev/null || true
rm -f /etc/nginx/sites-enabled/shopradar-api
rm -f /etc/nginx/sites-available/shopradar-api
nginx -t 2>/dev/null && systemctl reload nginx || true
rm -rf /root/shopradar-backend
mkdir -p /root/shopradar-backend
ls -la /root/shopradar-backend/
```

最后一行应只有 `.` 和 `..`。

---

## 步骤 2：SFTP 只上传 `shopradar-server`

在 Cursor / VS Code：

1. 左侧找到文件夹 **`shopradar-server`**（不要选 ShopRadar 根目录）
2. **右键 `shopradar-server` → `SFTP: Upload Folder`**
3. 选配置 **`Vultr-API-only（只传 shopradar-server）`**

**禁止**：右键 ShopRadar 根目录 → Upload Project。

---

## 步骤 3：SSH 验证路径（必须对）

```bash
ls -la /root/shopradar-backend/server.js
ls -la /root/shopradar-backend/.env
ls -la /root/shopradar-backend/deploy/bootstrap.sh
```

**正确**：三个文件都存在，且**没有** `/root/shopradar-backend/shopradar-server/` 目录。

**错误**：若存在 `shopradar-backend/shopradar-server/` 或 `popup.js`，说明又传错目录 → 回到步骤 1 重来。

---

## 步骤 4：并网

```bash
export SHOPRADAR_DOMAIN=api.shopradar.uk
export CERTBOT_EMAIL=leo14881@icloud.com
bash /root/shopradar-backend/deploy/bootstrap.sh
```

---
